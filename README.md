

# 🎬 Netflix Clone – React

A modern and responsive movie discovery platform inspired by Netflix, built using React.js, Vite, Tailwind CSS, and The Movie Database (TMDB) API.

Discover trending movies, explore different genres, browse top-rated collections, and view detailed movie information through a clean and user-friendly interface.

## ✨ Features

- 🏠 **Home Page** – Featured movie banner and attractive hero section
- 🔥 **Trending Movies** – Explore trending movies
- ⭐ **Top Rated Movies** – Browse highly rated movies
- 🎭 **Genre-Based Categories** – Action, Adventure, Comedy, and more
- 🔍 **Movie Search** – Search for movies
- 🎬 **Movie Details** – View movie information and overview
- ▶️ **Trailer Preview** – Watch movie trailers
- 📱 **Responsive UI** – Modern dark theme for a better viewing experience
- ⚡ **Dynamic Movie Data** – Fetch movie information using TMDB API

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- Tailwind CSS
- React Router DOM
- React Icons
- TMDB API
